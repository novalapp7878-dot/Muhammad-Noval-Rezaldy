NusaBanjar adalah website sederhana yang dibuat untuk memperkenalkan kain sasirangan khas banjar, kalimantan selatan.
Website ini menggabungkan informasi mengenai Sasirangan dengan katalog produk dan fitur pemesanan sederhana.

Fitur:
- Beranda
- Informasi tentang sasirangan
- Daftar produk
- halaman pemesanan
- perhitungan jumlah dan total harga
- Responsive untuk dekstop dan mobile

Teknologi:
- HTML
- CSS
- JavaScript
